## 🎯 专业版核心功能

### 1. 聊天记录智能归档

**功能说明**:
- 自动监控飞书群聊
- 提取关键信息和决策
- 智能分类和标签
- 自动关联相关文档

**使用场景**:
```
群聊讨论 → 自动提取 → 记忆存储 → 可搜索
```

### 2. 会议纪要自动生成

**功能说明**:
- 飞书日历会议结束后自动处理
- 提取会议要点
- 生成待办事项
- 关联相关文档

**输出示例**:
```markdown
# 会议纪要 - 2026-03-28

## 参会人员
- 张三、李四、王五

## 讨论要点
1. Q2 销售目标
2. 新产品上线计划

## 决策事项
- ✅ 确定 Q2 目标为 500 万
- ✅ 新产品 4 月 15 日上线

## 待办事项
- [ ] 张三：准备产品文档
- [ ] 李四：联系客户
```

### 3. 语义搜索（向量检索）

**功能说明**:
- 使用向量模型（sentence-transformers）
- 理解语义，不用记关键词
- 支持多语言
- 相关性排序

**示例**:
```
搜索："上次讨论预算是什么时候？"
→ 自动找到相关会议记录和文档
```

### 4. 知识图谱可视化

**功能说明**:
- 可视化展示知识结构
- 显示文档关联关系
- 支持交互式探索
- 导出图谱图片
