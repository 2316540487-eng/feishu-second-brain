## 二、2026 CEO 五大战略优先事项 (Vistage)

### 1. 🎯 宏大思考，非增量式
- ❌ 避免：只关注下一季度生存
- ✅ 应该：挑战团队创新，设定远大目标
- **风险**: 增量思维会扼杀增长

### 2. 🤖 AI 战略整合
- 90% 高管计划增加 AI 预算
- AI 领导者收入增长是未采用者的 **1.7 倍**
- **关键**: 不是"是否用 AI"，而是"如何用 AI 创造差异化"

### 3. 👥 人才战略对齐业务
- HR 参与战略决策的程度影响 CEO 信任度
- 人才投资必须有明确 ROI
- **公式**: 人才密度 → 业务增长

### 4. 🎯 聚焦投资，拒绝分散
- 每个决策过滤问题:**"这让我们更擅长核心业务吗？"**
- 说"不"和说"是"同样重要
- **原则**: 增长来自聚焦，而非堆砌项目

### 5. 📊 关键指标优先
- 识别**唯一关键成功指标**
- 避免指标过多导致的噪音
- **原则**: 当一切都重要时，什么都不重要

## 三、决策思维模型库

### 第一性原理
```
问题 → 拆解到最基本事实 → 从本质重新构建
```
**用途**: 打破假设，发现真正机会

### SWOT 分析
```
优势 (S) | 劣势 (W)
---------+---------
机会 (O) | 威胁 (T)
```
**用途**: 快速评估战略位置

### 二八定律
```
80% 结果来自 20% 关键因素
```
**用途**: 识别并聚焦那 20%

### 奥卡姆剃刀
```
如无必要，勿增实体
```
**用途**: 选择最简单有效的方案

### 金字塔原理
```
结论先行 → 以上统下 → 逻辑递进
```
**用途**: 清晰表达决策和指令

## 四、决策流程

### 标准决策流程
```
1. 审视 → 快速扫描，判断是否符合大战略
2. 质询 → 发现漏洞，追问细节
3. 决策 → 通过/有条件通过/驳回
4. 指令 → 简练、有力、可执行
```

### 风险评估矩阵
| 影响 | 概率低 | 概率高 |
|------|--------|--------|
| **高** | 监控 | **一票否决** |
| **低** | 接受 | 谨慎执行 |

## 五、关键业务指标 (CEO 视角)

### 财务健康
- **现金流**: 生存底线
- **毛利率**: 商业模式健康度
- **获客成本 (CAC) / 生命周期价值 (LTV)**: 增长可持续性
  - 健康比例：LTV:CAC ≥ 3:1

### 增长动力
- **有机收入增长**: 投资者第一优先级
- **创新占比**: 新产品/服务收入比例
- **市场份额变化**: 竞争力指标

### 组织健康
- **人才密度**: 关键岗位胜任率
- **决策速度**: 从提议到执行的时间
- **战略对齐度**: 团队理解并执行战略的程度

## 七、决策检查清单

### 批准前必问
- [ ] 这个决策如何支持核心战略目标？
- [ ] 投入产出比是否清晰？
- [ ] 最坏情况是什么？能否承受？
- [ ] 是否有更简单的方案？
- [ ] 谁负责执行？是否有能力？

### 驳回了理由模板
- "方向错误，与核心战略不符"
- "ROI 不清晰，需要重新测算"
- "风险不可控，暂不执行"
- "资源应该聚焦在更高优先级事项"

## 八、沟通风格指南

### 指令格式
```
【决策】批准/驳回/修改
【理由】一句话说明核心原因
【下一步】明确的行动指令
【责任人】@具体人员
【时间】明确截止日期
```

### 语气原则
- 专业、自信、权威、冷静
- 只看功劳，不看苦劳
- 数据驱动，非情绪化
- 简洁有力，拒绝废话
