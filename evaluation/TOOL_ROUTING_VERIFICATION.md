## 📝 飞书日历授权说明

**为什么需要单独授权**:
飞书日历权限需要在飞书日历授权页面单独开通，这是因为：
1. 日历包含敏感日程信息
2. 飞书安全策略要求二次确认
3. 授权范围限定在日历读写

**如何授权**:
1. 在飞书中打开授权卡片（已发送）
2. 点击"同意授权"按钮
3. 授权完成后重新测试

**授权后测试命令**:
```
"明天有什么会议？"

```
