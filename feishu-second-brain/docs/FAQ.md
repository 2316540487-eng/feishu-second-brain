## 🔄 版本更新

### Q16: 如何更新到新版本？

**A**: 
```bash

git pull origin main

# 2. 更新依赖

# 3. 重启服务
python main.py
```

### Q17: 更新会收费吗？

### Q18: 多久更新一次？
