## 🚀 专业版交付流程（10 分钟）

### 第 1 步：创建/确认私有仓库（2 分钟）

**方式 A: 使用现有私有仓库**
```
1. 访问：https://github.com/2316540487-eng/feishu-second-brain-pro
2. 确认仓库存在且为空
3. 准备推送专业版代码
```

**方式 B: 创建新私有仓库**
```
1. 访问：https://github.com/new
2. Repository name: feishu-second-brain-pro-{用户 ID}
3. Visibility: Private ✅
4. 点击 "Create repository"
```

### 第 2 步：推送专业版代码（3 分钟）

```bash
# 1. 准备专业版代码
cd /Users/yy/.openclaw/workspace/feishu-second-brain-pro

# 2. 初始化 Git
git init

# 3. 添加所有文件
git add .

# 4. 提交
git commit -m "Initial release: Pro version for {用户名}"

# 5. 添加远程仓库
git remote add origin git@github.com:2316540487-eng/feishu-second-brain-pro.git

# 6. 推送
git push -u origin main
```

### 第 3 步：邀请用户（2 分钟）

```
1. 访问仓库：https://github.com/2316540487-eng/feishu-second-brain-pro
2. 点击 "Settings"
3. 左侧菜单 "Collaborators"
4. 点击 "Add people"
5. 输入用户 GitHub 用户名或邮箱
6. 选择权限：Write（可读写）
7. 点击 "Add {用户名}"
```

### 第 4 步：发送欢迎邮件（3 分钟）

**使用模板**: `templates/欢迎邮件模板.md`

**发送内容**:
- ✅ 访问链接

- ✅ 用户群二维码

**发送方式**:
- Email: 用户邮箱
- 微信：如果已加微信

## 📞 常见问题处理

### Q1: 用户说收不到邀请邮件

**处理**:
```
1. 检查邀请状态：Settings → Collaborators
2. 重新发送邀请
3. 提供直接链接：https://github.com/2316540487-eng/feishu-second-brain-pro/invite
4. 指导用户检查垃圾邮件
```

### Q2: 用户不会安装

**处理**:
```
1. 发送快速开始指南链接
2. 提供远程协助（腾讯会议/微信视频）
3. 录制安装视频教程
```

### Q3: 用户要求退款

**处理**:
```
1. 了解退款原因
2. 7 天内无理由 → 同意退款
3. 超过 7 天 → 协商部分退款或延期
4. 记录退款原因用于改进
```
