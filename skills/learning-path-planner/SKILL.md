# Learning Path Planner - 学习路径规划

## 功能说明

基于任务历史和技能熟练度，自动生成学习路径和优化建议。

## 核心能力

1. **技能差距分析**：当前技能 vs 目标技能
2. **学习路径规划**：推荐最优学习顺序
3. **进度追踪**：记录学习进展
4. **资源推荐**：推荐相关技能和文档

## 学习路径生成算法

```python
def generate_learning_path(current_skills, target_role, time_budget):
    """
    生成学习路径
    
    Args:
        current_skills: 当前技能列表及熟练度
        target_role: 目标角色（如"专家级助手"）
        time_budget: 时间预算（如"10h/周"）
    
    Returns:
        learning_path: 学习路径（技能列表 + 预计时间）
    """
    # 1. 分析技能差距
    gaps = analyze_skill_gaps(current_skills, target_role)
    
    # 2. 构建技能依赖图
    dependency_graph = build_dependency_graph(gaps)
    
    # 3. 计算最优路径
    path = find_optimal_path(dependency_graph, time_budget)
    
    # 4. 添加资源推荐
    path_with_resources = add_resources(path)
    
    return path_with_resources
```

## 目标角色定义

| 角色 |  required 技能 | 预计时间 |
|------|--------------|---------|
| **通用助手** | 系统配置/文档编写/数据分析 | 已达成 |
| **专家级助手** | + 问题排查优化/网络策略/长对话管理 | 1-2 周 |
| **编程助手** | + 代码生成/代码审查/TDD 工作流 | 2-4 周 |
| **运维专家** | + 系统监控/自动备份/故障恢复 | 2-3 周 |
| **全能助手** | 以上所有 | 4-8 周 |
