## 🔐 GitHub 发布经验

### SSH Key 方式
- 生成命令：`ssh-keygen -t ed25519 -C "email" -f ~/.ssh/openclaw_github -N ""`
- 添加到 GitHub: https://github.com/settings/keys
- 遇到问题：格式验证失败，重新生成后解决

### Personal Access Token 方式
- Fine-grained token 更安全
- 必需权限：Contents (Read and write), Metadata (Read-only)
- 仓库访问：Only select repositories → 选择特定仓库
- Token 只显示一次，需立即复制保存

### 发布流程
1. 创建 GitHub 仓库（公开）
2. 本地 git init + add + commit
3. 添加 remote origin
4. git push -u origin main
5. 上传收款码（微信/支付宝）
