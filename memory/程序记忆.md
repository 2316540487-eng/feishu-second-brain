## 失败模式

### 模式 1：权限不足
```
特征：
- 错误信息：sudo: a password is required
- 任务类型：系统级配置
- 解决方案：用户提供密码 或 用免密码方案

预防措施：
1. 优先使用免密码方案（如 caffeinate）
2. 需要 sudo 时提前说明
```

### 模式 2：网络限制
```
特征：
- 错误信息：Blocked: resolves to private/internal IP
- 任务类型：网页抓取
- 解决方案：用 web_search 替代 web_fetch

预防措施：
1. 优先用 web_search
2. 需要 web_fetch 时先测试
```

### 模式 3：上下文丢失
```
特征：
- 用户说"你怎么没回复"
- 任务类型：长对话
- 解决方案：主动确认、定期总结

预防措施：
1. 长任务分阶段确认
2. 每 5 条消息总结一次
```
