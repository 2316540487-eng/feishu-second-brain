### 2. v3.22 大版本升级（2026-03-22）
**来源**: 36 氪 - https://eu.36kr.com/zh/p/3736233556033543

**核心变化**:

#### 🧩 插件系统重构
- 旧 API `openclaw/extension-api` 彻底移除
- 新 SDK `openclaw/plugin-sdk/*` 全面接管
- 插件安装默认来源从 npm 改为 **ClawHub**（官方市场）
- 新增对 Claude、Codex、Cursor 插件包的支持

#### 🔒 安全加固
- 封锁 JVM 注入路径（MAVEN_OPTS、SBT_OPTS、GRADLE_OPTS）
- 拦截 .NET 依赖劫持（DOTNET_ADDITIONAL_DEPS）
- 修复韩文填充码位伪装命令漏洞
- 预认证 body 限制：64KB/5 秒（之前 1MB/30 秒）

#### 🤖 模型生态扩张
- 默认 OpenAI 模型 → **GPT-5.4**
- MiniMax 默认模型 → **M2.7**（从 M2.5 升级）
- Anthropic Vertex 正式接入（通过 Google Vertex AI 调用 Claude）
- xAI Grok 目录同步
- Z.AI GLM 更新到 4.5/4.6 系列

#### 📱 多平台体验优化
- Android 深色模式支持
- Control UI 圆角滑块自定义
- 话题标签自动生成（LLM 生成有意义的标题）
- 结构化交互审批卡片
- 推理流（Reasoning Stream）实时显示

#### 💡 新功能
- `/btw` 命令：插入旁白问题，不影响上下文
