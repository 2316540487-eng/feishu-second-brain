## 📚 学习要点

### 1. Supermemory Skill - 向量记忆增强

**功能**: `@openclaw/supermemory`
- 使用向量数据库提供跨会话长期记忆
- 本地嵌入模型（nomic-embed-text）
- SQLite + 向量索引，数据完全本地

**Capabilities**:
```
- remember-fact      # 记住事实
- recall-relevant    # 召回相关记忆
- forget-memory      # 删除记忆
- list-memories      # 列出记忆
- search-memories    # 搜索记忆
```

**建议**: 🟡 中期评估安装

---

### 2. 记忆管理命令

| 命令 | 作用 | 使用场景 |
|------|------|----------|
| `/compact` | 压缩会话上下文 | 长对话后，Token 过高 |
| `/reset` | 重置短期上下文 | 切换话题，保留长期记忆 |
| `/new` | 开启全新对话 | 完全隔离的上下文 |
| `openclaw memory index` | 重建记忆索引 | 修改记忆文件后必行 |

---

### 3. 自动记忆触发配置

**Gateway 配置**:
```json
{
  "agents": {
    "defaults": {
      "compaction": {
        "memoryFlush": {
          "enabled": true,
          "softThresholdTokens": 4000,
          "prompt": "Write any lasting notes to memory/YYYY-MM-DD.md"
        }
      }
    }
  }
}
```

**作用**: 会话接近压缩时，自动提示存储重要记忆

## 💡 关键洞察

### 1. 记忆需要主动管理
- ❌ 不是写完就不管了
- ✅ 定期清理、提炼、重组

### 2. 索引重建很重要
- ❌ 修改文件后不重建索引
- ✅ 每次修改后执行 `openclaw memory index`

### 3. 分层管理更高效
- ❌ 所有记忆一个文件夹
- ✅ 按价值/时间分层管理

### 4. 向量检索是趋势
- ❌ 仅关键词搜索
- ✅ 语义搜索 + 向量检索

### 5. 记忆质量 > 数量
- ❌ 追求记忆文件数量
