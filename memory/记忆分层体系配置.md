## 📋 各层级说明

### 1. daily/ - 每日记忆

**保留期**: 30 天  
**内容**:
- 日常对话摘要
- 临时任务记录
- 短期上下文

**自动清理**: 超过 30 天的文件自动归档到 weekly

**示例**:
```markdown
# 2026-03-27 每日记忆

## 重要对话
- 用户询问 AI Agent 最新进展
- 讨论了自主学习系统配置

## 完成任务
- Golden Test Baseline 测试
- 工具路由修复

## 临时信息
- 用户明天上午 10 点有会议
```

---

### 2. weekly/ - 每周总结

**保留期**: 3 个月（12 周）  
**内容**:
- 每周学习总结
- 项目进展汇总
- 重要决策记录

**生成时间**: 每周日 23:00 自动生成

**示例**:
```markdown
# 2026-W13 周总结 (2026-03-24 ~ 2026-03-30)

## 本周学习
- 自主学习系统配置完成
- Golden Test 通过率 100%

## 项目进展
- 工具路由修复（6.5→9.0）
- 记忆系统增强

## 重要决策
- 采用 5 维度评估体系
- 建立每日学习报告机制
```

---

### 3. monthly/ - 月度洞察

**保留期**: 1 年（12 个月）  
**内容**:
- 月度趋势分析
- 能力提升总结
- 长期洞察

**生成时间**: 每月最后一天自动生成

**示例**:
```markdown
# 2026-03 月度洞察

## 核心成就
- 自主学习系统建立
- Golden Test 从 80%→100%

## 能力提升
- tool_routing: +38%
- 综合得分：+11%

## 长期洞察
- 工具路由配置至关重要
- 定期评估驱动持续改进
```

---

### 4. permanent/ - 永久记忆

**保留期**: 永久（除非手动删除）  
**内容**:
- 用户偏好
- 核心项目信息
- 关键学习成果

**文件列表**:
```
permanent/
├── preferences.md    # 用户偏好、习惯、风格
├── projects.md       # 进行中的项目信息
├── learnings.md      # 核心学习、原则、方法论
└── relationships.md  # 重要人际关系、团队信息
```

---

## 🔄 记忆流转机制

```
日常对话 → daily/ (30 天) → weekly/ (3 个月) → monthly/ (1 年) → permanent/ (永久)
                ↓                  ↓               ↓              ↓
           自动清理          提炼摘要        提炼洞察       手动维护
```

### 提炼规则

**daily → weekly**:
- 提取重复出现的主题
- 汇总任务完成情况
- 记录重要决策

**weekly → monthly**:
- 识别趋势和模式
- 总结能力提升
- 提炼长期洞察

**monthly → permanent**:
- 核心价值观念
- 持久性项目信息
- 关键关系网络

## 🛠️ 管理命令

### 查看各层级记忆
```bash
# 查看每日记忆（最近 7 天）
ls -lt memory/daily/ | head -7

# 查看每周总结
ls memory/weekly/

# 查看月度洞察
ls memory/monthly/

# 查看永久记忆
ls memory/permanent/
```

### 记忆维护
```bash
# 重建记忆索引（修改后必行）
openclaw memory index

# 查看记忆状态
openclaw memory status

# 搜索所有层级
openclaw memory search "关键词"
```

### 自动清理（建议配置 Cron）
```bash
# 清理超过 30 天的 daily 记忆
find memory/daily/ -name "*.md" -mtime +30 -exec mv {} memory/archive/ \;

# 清理超过 12 周的 weekly 记忆
find memory/weekly/ -name "*.md" -mtime +84 -exec mv {} memory/archive/ \;

# 清理超过 12 个月的 monthly 记忆
find memory/monthly/ -name "*.md" -mtime +365 -exec mv {} memory/archive/ \;
```
