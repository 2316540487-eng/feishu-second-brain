## 💡 方法论

### Golden Test 方法

**定义**: 建立标准化测试集，定期运行检测退化

**流程**:
```
1. 定义测试用例（覆盖关键场景）
2. 运行测试获取基线
3. 识别弱点和失败用例
4. 针对性修复
5. 重新验证
6. 持续监控
```

**关键指标**:
- 通过率（目标 >90%）
- 维度得分（5 维度）
- 趋势变化

**应用场景**:
- 工具路由优化
- 安全性测试
- 输出质量评估
- 记忆使用效率

---

### Ablation Testing（消融测试）

**定义**: 系统性移除组件，测量对整体性能的影响

**流程**:
```
1. 定义 baseline 配置
2. 设计消融条件（移除某组件）
3. 运行相同测试集
4. 对比性能差异
5. 计算影响值（Cohen's d）
6. 识别核心组件
```

**影响值解读**:
- d > 0.8: 核心组件（不可移除）
- d = 0.5-0.8: 重要组件
- d = 0.2-0.5: 辅助组件
- d < 0.2: 可考虑移除

**应用场景**:
- 配置文件优化
- 技能效果评估
- 工具重要性分析

---

### 记忆分层管理

**原则**: 按价值和时效性分层

**层级**:
```
daily (30 天) → weekly (3 个月) → monthly (1 年) → permanent (永久)
```

**提炼规则**:
- daily → weekly: 提取重复主题、汇总完成情况
- weekly → monthly: 识别趋势、总结能力提升
- monthly → permanent: 核心价值观、关键项目

**好处**:
- 降低检索成本
- 提升记忆质量
- 便于趋势分析
- 自动清理低价值内容

## 🎓 学习心得

### 关于自主学习

1. **持续性比强度重要**
   - 每天学习一点 > 偶尔突击
   - 建立习惯比单次收获更重要

2. **输出驱动输入**
   - 为了写报告而学习更高效
   - 教是最好的学

3. **反馈循环至关重要**
   - 学习→实践→评估→改进
   - 没有反馈的学习是盲目的

### 关于记忆管理

1. **记忆需要主动管理**
   - 不是写完就不管了
   - 定期清理、提炼、重组

2. **索引重建很重要**
   - 修改文件后必行
   - 否则搜索找不到

3. **分层提升效率**
   - 不同价值不同对待
   - 自动清理低价值内容

### 关于工具路由

1. **明确触发词**
   - 列出所有可能的用户表达
   - 包括同义词、口语化表达

2. **提供示例**
   - 展示完整调用流程
   - 包含参数说明

3. **持续测试**
   - 定期运行 Golden Test
   - 监控退化
