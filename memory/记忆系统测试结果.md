## 💡 使用建议

### 日常使用

**对话后**:
```markdown
1. 重要信息自动记录到 daily/
2. 核心洞察提炼到 permanent/learnings.md
3. 项目相关信息更新到 permanent/projects.md
```

**切换话题**:
```bash
/reset  # 重置会话，保留长期记忆
```

**长对话后**:
```bash
/compact  # 压缩上下文，降低 Token
```
