## 🛠️ 新增能力

### 1. 记忆分层管理

**层级**:
- daily (30 天) - 日常记忆
- weekly (3 个月) - 每周总结
- monthly (1 年) - 月度洞察
- permanent (永久) - 核心信息

**好处**:
- 自动清理低价值内容
- 提炼高价值洞察
- 便于趋势分析

### 2. 记忆管理命令

| 命令 | 作用 |
|------|------|
| `/compact` | 压缩会话上下文 |
| `/reset` | 重置会话（保留长期记忆） |
| `/new` | 开启全新对话 |
| `openclaw memory index` | 重建记忆索引 |
| `openclaw memory status` | 查看记忆状态 |

### 3. 永久记忆库

**文件**:
- `preferences.md` - 用户偏好（860 字）
- `projects.md` - 项目信息（1678 字）

**价值**:
- 持久保存核心信息
- 避免重复说明
- 建立知识体系

## 💡 关键洞察

### 1. 记忆需要主动管理
- ❌ 不是写完就不管了
- ✅ 定期清理、提炼、重组

### 2. 分层提升效率
- ❌ 所有记忆一个文件夹
- ✅ 按价值/时间分层管理

### 3. 索引重建很重要
- ❌ 修改文件后不重建索引
- ✅ 每次修改后执行 `openclaw memory index`

### 4. 向量检索是趋势
- ❌ 仅关键词搜索
- ✅ 语义搜索 + 向量检索（Supermemory）

### 5. 记忆质量 > 数量
- ❌ 追求记忆文件数量
- ✅ 注重记忆质量和可用性
