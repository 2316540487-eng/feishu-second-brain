## 📚 核心知识点

### 1. Supermemory Skill - 向量记忆增强

**功能**: `@openclaw/supermemory`
- 使用向量数据库提供跨会话的长期记忆能力
- 本地嵌入模型（nomic-embed-text）向量化记忆内容
- 存储于 SQLite + 向量索引，数据完全本地化

**Capabilities**:
```
- remember-fact      # 记住事实
- recall-relevant    # 召回相关记忆
- forget-memory      # 删除记忆
- list-memories      # 列出记忆
- search-memories    # 搜索记忆
```

**对我们的价值**: ⭐⭐⭐⭐⭐
- ✅ 当前已使用 `memory_search`（语义搜索）
- ⚠️ 可考虑安装 Supermemory 增强向量检索能力

---

### 2. 记忆调用优化技巧

#### `/compact` 命令
- **作用**: 压缩当前会话上下文
- **场景**: 对话很久后，Token 消耗过高
- **效果**: 保留关键信息，丢弃细节

#### `/reset` 命令
- **作用**: 重置短期上下文，保留长期记忆
- **场景**: 结束一个话题，开始全新话题
- **效果**: 清理会话历史，MEMORY.md 不受影响

#### `/new` 命令
- **作用**: 开启全新对话（类似新建标签页）
- **场景**: 需要完全隔离的上下文
- **效果**: 从零开始，无任何历史负担

---

### 3. 记忆索引重建

**命令**:
```bash
openclaw memory index    # 重建记忆索引（修改文件后必行）
openclaw memory status   # 查看记忆状态
openclaw memory search "关键词"  # 语义搜索
```

**重要性**: ⭐⭐⭐⭐⭐
- 修改 MEMORY.md 或 memory/*.md 后必须重建索引
- 否则语义搜索可能找不到最新内容

---

### 4. 自动记忆触发配置

**Gateway 配置示例**:
```json
{
  "agents": {
    "defaults": {
      "compaction": {
        "reserveTokensFloor": 20000,
        "memoryFlush": {
          "enabled": true,
          "softThresholdTokens": 4000,
          "systemPrompt": "Session nearing compaction. Store durable memories now.",
          "prompt": "Write any lasting notes to memory/YYYY-MM-DD.md; reply with NO_REPLY if nothing to store."
        }
      }
    }
  }
}
```

**作用**: 会话接近压缩时，自动提示存储重要记忆

## 💡 关键洞察

1. **记忆需要定期维护** - 不是写完就不管了
2. **索引重建很重要** - 否则搜索找不到新内容
3. **分层管理更高效** - 不同价值的记忆不同对待
4. **向量检索是趋势** - 语义搜索比关键词更强大
5. **记忆质量 > 数量** - 定期清理低价值内容
